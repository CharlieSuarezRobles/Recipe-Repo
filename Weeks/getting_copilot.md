## Optional: Get GitHub Copilot as a UCSD Student

GitHub provides eligible students with free access to Copilot’s premium features through GitHub Education.

> The questions GitHub asks and the time required for approval may differ for each student.

### 1. Add your UCSD email to GitHub

1. Sign in to [GitHub](https://github.com).
2. Click your profile picture in the upper-right corner.
3. Select **Settings**.
4. Under **Access**, select **Emails**.
5. Enter your `@ucsd.edu` email under **Add email address**.
6. Click **Add**.
7. Open your UCSD email inbox and find the verification email from GitHub.
8. Click **Verify email address**.

You can keep your personal email as your primary GitHub email. Your UCSD email only needs to be added and verified.

### 2. Apply for GitHub Education

1. Open the [GitHub Education benefits page](https://github.com/settings/education/benefits).

2. Click **Start an application**.

3. Enter the requested information.

4. If requested, provide proof that you are currently a student. GitHub may accept documents such as:

   * A UCSD student ID showing a current enrollment date
   * A current class schedule
   * A transcript
   * An enrollment-verification letter

5. Submit the application.

6. Wait for GitHub to email you its decision.

### 3. Activate Copilot Student

After GitHub approves your application:

1. Return to the [GitHub Education benefits page](https://github.com/settings/education/benefits).
2. Find the Copilot Student benefit.
3. Click **Learn more**.
4. Follow the instructions to activate Copilot Student.
5. Choose your preferred Copilot usage settings.

Approval for GitHub Education and activation of Copilot are separate steps. Copilot may take several days to recognize your approved student status. If GitHub only displays paid options, do not provide payment information. Wait a few days and try again.

### 4. Use Copilot in VS Code

1. Open VS Code.
2. Make sure you are signed in using the same GitHub account that received the student benefit.
3. Open the **Extensions** tab.
4. Search for **GitHub Copilot**.
5. Install or enable the extension.
6. Follow any prompts to authorize VS Code to use your GitHub account.

GitHub Copilot should now be available inside VS Code.
